# Hands-free mode and Rewrite mode — design

Date: 2026-10-15 · Status: approved in chat, pending spec review

Two new ways to use the fn hotkey, on top of today's hold-to-dictate:

1. **Hands-free mode** — double-tap fn to dictate without holding the key.
2. **Rewrite mode** — select text, hold fn + Control, say what to do with it
   ("bullet points", "more formal", "as a poem"), release; the selection is
   replaced by the rewritten text.

Out of scope: preview/accept dialogs, Esc-to-cancel, rewriting without a
selection (generating new text), saved rewrite presets, engine changes
(Whisper stays the STT engine).

## 1. Hands-free mode

### Behaviour

| Gesture | Result |
|---|---|
| Hold fn ≥ 0.3 s, release | Unchanged: normal dictation |
| Tap fn, then press fn again within 0.4 s of the tap's release | Hands-free recording starts on the second press; releasing does **not** stop it |
| While hands-free: press fn (tap) | Stops recording → transcribe → clean → paste, as normal |
| While hands-free: `handsfree_max_s` reached (default 600 s) | Force-stop and process, like today's max-duration path |

A "tap" is a press whose release comes < `min_duration_s` (0.3 s) after the
press. The first tap of a double tap is discarded exactly as today's taps are
(it briefly opens the recorder; that is acceptable and keeps the hotkey path
unchanged). Holding fn+Control never triggers hands-free.

### Feedback

- **Sound:** new `rec_handsfree.wav`, a three-note rising chime generated by
  `packaging/make_sounds.py` in the same style as the existing chimes; played
  instead of the start chime when hands-free begins. Capture is muted for its
  duration (same `mute_for` mechanism). Stop chime unchanged.
- **Overlay:** the pill switches to a `handsfree` style: green accent (the
  app's brand green) instead of the blue-grey gradient, a small lock glyph left
  of the waveform, and a slow pulsing border while recording.
- **Menu bar:** state `handsfree` with icon `🔒`.

### Config

`[audio] handsfree_max_s = 600` (new, documented in `config.toml`).

## 2. Rewrite mode

### Behaviour

1. User selects text in any app.
2. User holds fn and Control (either order; pressing Control while fn is
   already held converts the running recording into a rewrite).
3. Overlay shows the `command` style: pill widened with the label
   **"What should I do with it?"** above/next to the waveform.
4. User speaks the instruction and releases fn.
5. Overlay shows **"Rewriting…"**. Pipeline:
   1. Transcribe the instruction with Whisper (no dictionary `initial_prompt`
      needed, but harmless if reused).
   2. Wait for modifiers to be released, send Cmd+C, read the selection from
      the pasteboard, restore the previous pasteboard contents.
   3. One LLM call: system prompt = "Rewrite the user's text according to the
      instruction. Return only the rewritten text. Keep the original language
      unless the instruction asks otherwise. Preserve meaning unless asked to
      change it." User content = instruction + text (clearly delimited).
   4. Paste the result over the still-active selection via `insert_text`.
6. Cmd+Z in the target app restores the original (no app-side undo needed).

### Failure handling

| Case | Behaviour |
|---|---|
| Clipboard unchanged after Cmd+C (nothing selected / app refused copy) | Overlay message "Select some text first" for 2 s; nothing pasted |
| Instruction transcript empty or < 2 characters | Overlay message "Didn't catch that" for 2 s; nothing pasted |
| No API key / cleanup unavailable | Overlay message "Rewrite needs an API key"; nothing pasted |
| LLM error, timeout (10 s), truncated or empty reply | Overlay message "Rewrite failed"; original text untouched; logged |

The selected text is never deleted unless a complete rewrite is ready to paste.

### History & insights

- `history` gains a column `kind TEXT DEFAULT 'dictation'` (added by an
  idempotent migration on startup). Rewrites store `kind='rewrite'`,
  `raw` = spoken instruction, `text` = rewritten result.
- Insights (WPM, words, fixes, streak, app usage) count only
  `kind='dictation'`. Rewrites never feed dictionary learning.
- The History list shows a small "Rewrite" badge on rewrite entries.

## 3. Architecture

| Unit | Change |
|---|---|
| `flow/hotkey.py` `FnHotkeyListener` | Reads the Control flag on every flagsChanged event. Callbacks become `on_hold_start(mode)`, `on_hold_end()`, plus `on_mode_change(mode)` when Control is pressed mid-hold. Double-tap detection (tap release → next press within 0.4 s) emits mode `handsfree`. Pure timing/flag logic stays testable without AppKit. |
| `flow/pipeline.py` | Recording carries a `mode` (`dictation` / `handsfree` / `command`). In `handsfree`, `on_hold_end` is ignored and the next `on_hold_start` stops the recording. On finish, `command` recordings go to the transform path instead of cleanup→paste. |
| `flow/transform.py` (new) | `grab_selection() -> str | None` (Cmd+C + pasteboard snapshot/restore, reusing `insert.py` helpers) and `build_rewrite_messages(text, instruction)`. |
| `flow/cleanup.py` `Cleaner` | New `rewrite(text, instruction) -> str | None` reusing the provider plumbing (OpenRouter / Anthropic), plain-text reply, truncation → `None`. |
| `flow/overlay.py` | `show(style)` with styles `dictation` / `handsfree` / `command`; `flash(message)` for short status messages ("Rewriting…", errors). |
| `flow/sound.py` | `play_handsfree()` + duration helper. |
| `flow/store.py`, `flow/ui/app.js` | `kind` column, insights filter, history badge. |
| `flow/menubar.py` | `handsfree` icon. |
| `flow/config.py`, `config.toml` | `handsfree_max_s`. |

## 4. Testing

- Hotkey: hold → dictation; tap+press < 0.4 s → handsfree; tap + press after
  0.5 s → dictation; fn then Control → mode change to command; Control then fn
  → command; Control never yields handsfree.
- Pipeline: handsfree ignores release and stops on next press; max duration
  uses `handsfree_max_s`; command recording calls transform path, not cleanup.
- Transform: no selection → no paste; LLM failure → no paste; success → paste
  once with result; prompt contains instruction and text, delimited.
- Store: migration is idempotent on an existing DB; insights exclude rewrites.
- Manual UAT: hands-free chime/overlay/menubar; rewrite in Notes, Mail,
  browser text field, VS Code; Cmd+Z restores original.
